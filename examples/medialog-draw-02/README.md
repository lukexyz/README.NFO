# MediaLog — ten fresh directions

[Open the gallery](gallery.html) · [Saved random draw](draw.json) · [Project facts](project.json) · [QA record](qa.json)

Ten original SVG headers, plus two text / ASCII alternatives. This draw excludes the first MediaLog set and previous saved README.NFO, Heretic and Pliny draws. The user’s description and screenshots supplied the project facts; diary conversations and retro interfaces are illustrative.

**Everything you’ve watched, read, played, listened to, on one timeline.**

To install a choice, copy its SVG to `docs/readme-headers/medialog-draw-02/assets/` in your project and copy its [MIT notice](LICENSE.README-NFO.txt) beside the assets directory. Use the gallery’s Copy Markdown button, or adjust the path to wherever you put the image. Numbered preview pages use local paths. No remote fonts, scripts or images are required by the SVGs.

Rebuild all ten: `node examples/medialog-draw-02/src/build.mjs`. Each numbered generator owns its composition; shared files supply only geometry and lettering.
