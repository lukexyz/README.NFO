# MediaLog — compact logo collection 02

[Open the actual-size gallery](gallery.html) · [Contact sheet](preview.png) · [Saved random draw](draw.json) · [Project brief](project.json) · [Checks](qa.json)

Twenty original graphic logos, designed for **203 × 74 pixels** (viewBox 812 × 296). No ASCII or character art. Motifs reinterpret a shared media diary; the screenshot supplied the size and aspect ratio. A graphic-first pool was frozen before the random draw, with previous saved styles excluded.

Each design includes a self-contained SVG, a static SVG, and transparent 812 × 296 PNG exports for light and dark surroundings. Adaptive SVG colours follow the embedding page’s colour scheme. Dark-panel designs retain their panel. PNGs are browser exports of the SVG artwork.

## Use a logo

Copy the chosen SVG and [MIT notice](LICENSE.README-NFO.txt) into your project. The gallery’s Markdown uses `docs/brand/medialog-logos-02/assets/`; change the path if you save it elsewhere. Keep the width and height at 203 × 74, or scale both proportionally. There is no unreadable tagline inside the mark.

Rebuild vector artwork and gallery with `node examples/medialog-logos-02/src/build.mjs`. Export PNGs with `node examples/medialog-logos-02/src/export-png.mjs` from this repository (Playwright and Chromium required). Source generators are independent compositions; `lib.mjs` contains the original letter paths and drawing primitives.
