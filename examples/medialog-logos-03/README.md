# MediaLog — compact logo collection 03

[Open the actual-size gallery](gallery.html) · [Contact sheet](preview.png) · [Saved random draw](draw.json) · [Project brief](project.json) · [Checks](qa.json)

Twenty original graphic logos, designed for **203 × 74 pixels** (viewBox 812 × 296). No ASCII or character art. Motifs reinterpret a shared media diary; the screenshot supplied the size and aspect ratio. The user’s latest brief takes precedence: primary #18223a, plain lettering, restrained accents, a gentle diary preference. All previous MediaLog styles are excluded; references used for other projects may recur. The saved draw records the scope.

Each design includes a self-contained SVG, a static SVG, and transparent 812 × 296 PNG exports for light and dark surroundings. Adaptive SVG colours follow the embedding page’s colour scheme. Inverse artwork uses warm white on navy. Every symbol also has its own 64 × 64 SVG. PNGs are browser exports of the SVG artwork.

## Use a logo

Copy the chosen SVG and [MIT notice](LICENSE.README-NFO.txt) into your project. The gallery’s Markdown uses `docs/brand/medialog-logos-03/assets/`; change the path if you save it elsewhere. Retain the font notice with the full wordmark. Keep the width and height at 203 × 74, or scale both proportionally. There is no unreadable tagline inside the mark.

Rebuild vector artwork and gallery with `node examples/medialog-logos-03/src/build.mjs`. Export PNGs with `node examples/medialog-logos-03/src/export-png.mjs` from this repository (Playwright and Chromium required). Source generators are independent compositions; `lib.mjs` contains drawing primitives and reads `wordmark.json`. The wordmark uses DejaVu Sans Bold, converted to paths; retain [its font notice](LICENSE.FONT.txt). To change the title, edit `src/outline-wordmark.py` and run it with Python and fontTools. The font is bundled for reproducibility.
