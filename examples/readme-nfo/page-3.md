Enter the listing below. Replace brace tokens with the matching
screen keys on your chosen BASIC system. Keep your favourite style.

10 PRINT &quot;{CLR}{RVS}README.NFO{OFF}&quot;          :REM 208
20 REM RETRO HEADERS FOR YOUR REPOSITORY      :REM 228
30 REM TYPE IT IN. MAKE IT YOURS.             :REM  86
40 READ STYLES,FAMILIES                       :REM  26
50 PRINT STYLES;&quot; STYLES TO EXPLORE&quot;          :REM 155
60 PRINT FAMILIES;&quot; FAMILIES OF FIRST LOOKS&quot;  :REM 107
70 PRINT &quot;TEXT ART + SVG / MIT LICENCE&quot;       :REM 139
80 PRINT &quot;1 CATALOGUE  2 GALLERIES  3 TOOLS&quot;  :REM 173
90 INPUT &quot;CHOOSE A SECTION&quot;;N                 :REM  93
100 IF N=1 THEN GOSUB 1000                    :REM 236
110 IF N=2 THEN GOSUB 1100                    :REM 239
120 IF N=3 THEN GOSUB 1200                    :REM 242
130 GOTO 80                                   :REM 117
200 DATA 152,13,2026,10,5,0                   :REM  84
1000 PRINT &quot;STYLES/INDEX.MD&quot;:RETURN           :REM  54
1100 PRINT &quot;EXAMPLES/README.MD&quot;:RETURN        :REM 232
1200 PRINT &quot;NPM RUN PREVIEW&quot;:RETURN           :REM  48

CHECK COLUMN: sum the ASCII bytes BEFORE the :REM, modulo 256.
Exclude the padding spaces. Checksums describe this printed listing;
brace tokens are counted literally, before keyboard substitution.

                    README.NFO  -  OCTOBER 2026
