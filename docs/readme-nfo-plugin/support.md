# README.NFO Headers support

README.NFO Headers is published by **Luke Woods**. For questions, bugs and feature requests, use the public [README.NFO GitHub Issues page](https://github.com/lukexyz/README.NFO/issues).

Include the plugin version, your assistant environment, the requested header count or style ID, and a small non-sensitive example showing what you expected and what happened. A saved style-draw seed can help reproduce a selection problem. For a generation problem, include a screenshot or minimal source example only if you are comfortable making it public.

GitHub Issues are public. Do not post API keys, access tokens, passwords, private repository contents, personal information or other secrets. Reduce a private-repository problem to a public-safe example before reporting it.

The plugin does not operate a separate support database. Issue posts and attachments are hosted by GitHub. Use GitHub's controls to edit or remove your own content where available. If you need help with an issue's visible content, contact the repository maintainer through the issue tracker without adding sensitive details. GitHub account and platform-data requests should go to GitHub.
